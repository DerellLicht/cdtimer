# cdtimer Changelog

## [1.06] - 2023-07-24
- Add About dialog and other modern stuff

## [1.05] - 2023-05-12
- Add support for zplay library for audio playback. This enables playback of .mp3, .ogg, .flac, as well as .wav files

## [1.04] - 2018-03-12
- Extract Trackbar tool into separate file, move to der_libs.

## [1.03] - 2017-11-20
- Fixed init bug when setting time scale on slider, at startup.

## [1.02] - 2016-12-16
- Converted application to use dialog-based interface.

## [1.01] - 2010-12-24
- now has a Count Up mode, as well as normal CountDown.

## [1.00] - 2006-12-04
- program now allows the user to specify the sound file to be played when the timer expires. At this point, only .WAV files are supported.
